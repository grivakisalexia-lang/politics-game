# Path to Power: Political Science Game

A compact, single-page political science simulation where you craft a candidate profile, react to news events, and watch support shift across voter blocs.

## How to run

Open `index.html` in any modern browser. No build tools or dependencies are required.

## How to play

1. Set your candidate name, party, and initial stances on the economy, environment, and civil rights.
2. Hover the polling bars to read what each voter bloc cares about.
3. Click **Advance Turn** or choose a news event option to respond. Approval and momentum update in real time.
4. Reach **55% approval by turn 12** to meet the target.

Enjoy experimenting with different strategies and seeing how policy trade-offs affect the electorate!
